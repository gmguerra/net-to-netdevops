# ExpressRoute troubleshooting

There are three main routing domains:

- Azure network
- Internet or WAN
- Corporate on-prem

To troubleshoot the best these situations, customers should use the following steps:

## Verify the circuit and provider status

Microsoft circuit must be enabled and the provider status must be provisioned. 

## Verify the peering

Each ER circuit can have: an Azure private peering, an Azure public peering, and/or a Microsoft peering. The peering status in any case should be provisioned.

## Support

The azure portal has information on configuring and troubleshooting ER connections. The support Wizard is there to help customers identify and provide troubleshooting steps. To get assistance from Microsoft or from an ER partner, the service key must be provided.
